# Minecraft AI video files

Drop MP4 clips into this folder with these names:

- `hero.mp4`: "beat the game" in chat, then the first tree
- `mine.mp4`: mining stone or ore after getting wood
- `craft-smelt.mp4`: a quick craft and smelt
- `fight.mp4`: a mob fight during the run
- `nether-portal.mp4`: building and lighting a Nether portal
- `blazes.mp4`: killing blazes in the Nether
- `endermen.mp4`: killing Endermen for pearls
- `end-portal.mp4`: entering the End portal
- `pillar.mp4`: climbing an obsidian pillar in the End
- `dragon.mp4`: killing the Ender Dragon

The page detects each clip automatically. Until a file exists, its recording note remains visible. Keep clips around 10 seconds, landscape, and H.264 MP4. Visible clips play muted; hovering one restarts it and pauses the others.
