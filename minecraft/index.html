Minecraft AI

A bot that plays Minecraft with us.

It joins the server like any other player and does what you ask it to in chat. Nothing is modded in. It reads the same packets your game client reads, so the server cannot tell it apart from a person, and neither can anyone standing next to it. Drop it in a fresh world with nothing in its inventory and fifteen minutes on the clock, and it comes back holding an iron pickaxe.

Watch it play

Everything it does starts as a line of text it types to itself.

There is no controller and no keyboard behind any of this. The model writes !collectBlocks("oak_log", 4) into its own output, and the framework underneath reads that line and moves the body. So what you are watching is a language model picking the next thing to type, and a game client doing what it says.

One run, start to finish

Empty inventory, fifteen minutes, no help. This is the whole thing it has to get right.

01
Find wood It spawns with nothing, so the first move is always a tree. Sounds trivial. It is the step that used to send it walking hundreds of blocks past perfectly good spruce, because the code underneath had oak written into it and our world is a taiga.
02
Planks, sticks, a crafting table Its first real crafts, and the first time it has to plan two moves ahead. You ask for sticks, it needs planks, and planks need the logs it just cut. It works that chain out itself now, instead of getting stuck asking for the thing it cannot make yet.
03
A wooden pickaxe, then stone The first tool, which is what unlocks mining at all. Then it runs the whole sequence again one tier up: mine the stone, craft the stone pickaxe, because that is what iron needs.
04
Go find iron Downward, and this is where runs used to quietly die. Deep enough and the stone turns to deepslate, and the ore inside it has a different name. The search never knew that, so on the hardest part of the run it was hunting for a block that does not spawn down there.
05
Build a furnace and smelt Eight cobblestone, a fuel source, and the patience to stand there. The single biggest killer. Most failed runs got the ore out of the ground and then never turned it into a single ingot.
06
Craft the iron pickaxe Three ingots, two sticks, done. It has cleared this three times out of three from an empty inventory. Before the fixes below, it had never done it once.

Things that went wrong

Around twenty-five of these, and almost none of them were the model's fault. They were bugs in the framework it runs on, and they only ever surfaced because I was playing off the beaten path: a bot without admin rights, a spruce forest instead of an oak one, tiny models, run after run after run.

  • The scoreboard was lying to me. The test harness wipes the bot's inventory between runs with a command that needs admin rights, which my bot deliberately does not have. It failed silently and printed "cleared" anyway. So the bot started each run still holding the last run's gear, the scorer saw an iron pickaxe already in its hands, and it marked the run a win before the bot had moved. I had a perfect ten out of ten that meant absolutely nothing.
  • It counted blocks it never picked up. The counter ticked when the block broke, not when the item landed in the inventory. So it would announce it had collected a log, then immediately fail to craft planks for want of that exact log. Of the collections I checked, 71 % had nothing to show for them.
  • It kept looking for oak in a spruce forest. One hardcoded preference buried in the recipe sorting, and the error message it read back to itself named oak too, so off it went hunting for a tree our biome does not have.
  • You cannot tell it anything. This is the one that changed how I built everything after it. It ignored 224 warnings in a row. It called a command that had been deleted 292 times in a single run. It printed its own plan saying it needed to smelt, and then never smelted. Wording it better does nothing. The only thing that works is taking the decision away and doing it in code, which is why crafting now does its own smelting and the furnace builds itself.
  • Fixing all of it made it faster, not smarter. Fourteen fixes in one night took the share of turns that actually did something from 9 % to 97 %, and hallucinated commands from 292 down to 1. The success rate on the hardest run did not move at all. Worth being honest about: that work bought reliability, and none of it bought skill.

The code

This one isn't on GitHub

It is a heavily patched fork of mindcraft-ce, which drives the game through Mineflayer, with about twenty-five fixes of mine on top. It lives on my machine next to the server it plays on, and it never got cleaned up into something you could clone. Both of the projects underneath it are worth a look though.
