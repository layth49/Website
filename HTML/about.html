Bio

[ The short version ]

Most of what's on this site started the same way: something was repetitive, so I wrote code until it wasn't. Click a target, type a phrase, react to a color. That turned into aim, typing, and reaction bots, and the pattern never really stopped.

These days the biggest thing I've built is L.A.I.T.H.49, a voice assistant that decides on the fly which of its 38 tools to run for whatever I just asked it. It screens my calls, keeps standing rules going while I'm out, and comes back from a reboot without forgetting what it was doing. I'm also building Burhan, an app that answers questions about Islam with the actual verse text instead of letting a chatbot improvise one.

When I'm not scripting software, I'm usually trying to script hardware instead. Arduinos, servos, motors, and lately a door that opens itself because I got tired of standing up to do it.
